## Game Jam Project

Game made in 48 hours for **CtrlShiftCreate** Game Jam hosted by ITAM MISIS.

## Gameplay video
[![Watch the demo](https://github.com/user-attachments/assets/e2c81eca-bc18-4dce-a7a3-8e5778bc86fd)](https://www.youtube.com/watch?v=jS8UT7jky1A)

## Used packages:

| Package | Version | Type |
|---|---|---|
| **Post Processing** | v3.2.2 | Visuals
| **Cinemachine** | v2.6.17 | Camera controls
| **TextMeshPro** | v2.1.6 | Text
| **DOTween** | Free | Animating
| **Realtime-CSG** | v1.562 | Level-editing

Open with Unity 2019.4.40f1
